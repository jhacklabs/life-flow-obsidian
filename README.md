# زندگی‌آرام (LifeFlow)

مدیریت کامل زندگی روزمره — تسک‌ها، برنامه‌ریزی روزانه، پومودورو، یادگیری، مطالعه، ورزش و یادداشت‌ها — همه در یک پلاگین اوبسیدین، با تقویم کاملاً شمسی (جلالی/هجری شمسی) در تمام بخش‌ها.

LifeFlow اصلاً یک اپ وب مستقل بود که کامل تبدیل به پلاگین اوبسیدین شده؛ داده‌هات همیشه داخل همین ولت و به‌صورت محلی ذخیره می‌شه.

## ویژگی‌ها

- **تسک‌ها**: ماتریس آیزنهاور، نمای کانبان، اولویت‌بندی، برچسب، زیرتسک
- **تسک روند‌دار (Progressive)**: به‌جای انجام‌شد/نشد، یه هدف عددی تعریف می‌کنی (مثلاً «۶۰۴ صفحه») و هر روز پیشرفتش رو ثبت می‌کنی
- **تکرار پیشرفته**: روزانه، هفتگی (با روزهای دلخواه)، ماهانه و سالانه (بر پایه‌ی تقویم شمسی)، و همچنین روزهای زوج/فرد
- **تقویم**: نمای روزانه با برنامه‌ریز درگ‌اند‌دراپ (قابل تغییر زمان و مدت با کشیدن)، و نمای هفتگی/ماهانه/سالانه — همه‌جا شمسی
- **پومودورو**: تایمر کامل با اختصاص تسک، ثبت جلسه، و گزارش (روزانه/هفتگی، به تفکیک تسک)
- **یادگیری**: برای هر موضوع (مثلاً «حفظ قرآن») به تعداد دلخواه زیربخش تعریف کن (تثبیت، مرور، حفظ...)، هرکدوم با هدف، واحد سنجش، و تاریخ هدف شمسی
- **برنامه‌ریزی روزانه** (زمان روز → گروه → تسک)، **اهداف بلندمدت**
- **مطالعه، ورزش، یادداشت‌ها و دفترچه‌ی روزانه**
- **گیمیفیکیشن** (سطح و امتیاز بر اساس فعالیت)
- **جستجوی سراسری** بین همه‌ی بخش‌ها
- **بکاپ و بازگردانی کامل** + **همگام‌سازی ابری اختیاری**
- **اعلان‌ها**: یادآوری تسک، پایان پومودورو، نزدیک‌شدن به ددلاین یادگیری، خلاصه‌ی صبحگاهی — هرکدوم جدا قابل خاموش/روشن‌کردن
- ۴ زبان (فارسی، انگلیسی، فرانسه، عربی) و تم روشن/تاریک

## نصب

### روش دستی
۱. آخرین نسخه رو از [Releases](../../releases) دانلود کن (سه فایل `main.js`, `manifest.json`, `styles.css`)
۲. این سه فایل رو بریز تو `<ولت‌شما>/.obsidian/plugins/lifeflow/`
۳. اوبسیدین → Settings → Community plugins → مطمئن شو Restricted mode خاموشه → «زندگی‌آرام» رو پیدا کن و روشنش کن

### از طریق Community Plugins (در صورت تأیید)
تو اوبسیدین: Settings → Community plugins → Browse → جستجوی «زندگی‌آرام» یا «LifeFlow»

### از طریق BRAT (نسخه‌های بتا/زودتر)
با پلاگین [BRAT](https://github.com/TfTHacker/obsidian42-brat) آدرس همین ریپو رو اضافه کن.

## توسعه

```bash
npm install
npm run dev     # ساخت با watch
npm run build   # ساخت نهایی + اجرای تست‌های اسموک (شبیه‌سازیِ کامل چرخه‌ی بارگذاری در اوبسیدین)
```

`npm run build` علاوه بر ساخت فایل‌ها، پلاگین رو در یک محیط شبیه‌سازی‌شده‌ی اوبسیدین واقعاً **اجرا** می‌کنه (نه فقط کامپایل) تا مطمئن بشه واقعاً بالا میاد.

## داده و حریم خصوصی

تمام داده‌ها به‌صورت پیش‌فرض فقط داخل همین ولت ذخیره می‌شن (از طریق API محلیِ خودِ اوبسیدین). همگام‌سازی ابری کاملاً اختیاریه و فقط با پیکربندی دستیِ خودت فعال می‌شه.
